# 🔬 Featured Research

## 🏆 RoME — Robust Multimodal Experts

**Scientific Reports (2026)**

RoME studies robust multimodal sentiment analysis under missing-modality conditions. The framework focuses on learning stronger modality representations, cross-modal interactions, and reliable fusion when different information sources are unavailable.

Research areas:

`Multimodal Learning` · `Missing Modalities` · `Sentiment Analysis` · `Mixture of Experts` · `Cross-Modal Learning`
